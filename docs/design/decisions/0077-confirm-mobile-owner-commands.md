# ADR-0077: подтверждать команды владельца сертификатом телефона и выбором операции

- **Status:** `accepted`
- **Date:** `2026-11-23`
- **Owner:** инструменты разработки и обвязка агентов
- **Decision basis:** [решение владельца о мобильном подтверждении](../../exec-plans/active/2026-11-22-agent-workflow-mobile-control.md#сводка-для-продолжения)

## Проблема

Владелец управляет задачами нескольких проектов с телефона. Одинаковое имя задачи может
встречаться в разных проектах. У решения из браузера есть свой источник полномочия.

## Факторы и ограничения

Сервер на Mac уже проверяет сертификат телефона и отзыв устройства. Права проекта,
допуск на старт, ожидаемая редакция и состояние исполнения проверяются для каждой операции.

## Рассмотренные варианты

- **Выбрано:** предъявление привязанного сертификата и явное подтверждение точной операции
  в браузере владельца.
- Дополнительное подтверждение на Mac потребовало бы присутствия владельца у компьютера.

## Решение

При подтверждении сервер проверяет сертификат и связывает владельца с проектом, задачей,
запуском и ожидаемой редакцией. Для решения по вопросу привязка включает сам вопрос
и точный ответ. При старте подтверждаются проект, параметры и бюджет до создания запуска.
Мобильное подтверждение сохраняет собственное происхождение. Источник решения из чата Codex
сохраняет [прежний договор](inherited/0050-recover-workflow-owner-and-user-commands.md).

## Обоснование

Проверка устройства идентифицирует владельца. Подтверждение связывает его решение с
показанными параметрами одной операции.

## Последствия

Утраченный телефон требует отзыва на Mac. Для записи нужны защита от запросов с чужой
страницы, сохраняемая квитанция и проверка актуальности перед исполнением.

## Проверка

Проверить подмену проекта, задачи, запуска, редакции или содержимого, отзыв телефона и
повтор команды после потери ответа. На устройстве отдельно сверить показанные параметры
и подтверждённый эффект. Приёмка мобильного чтения предшествует включению записи.

## Условие пересмотра

Появление второго владельца или другого способа входа требует пересмотра связи устройства
с владельцем и правил отзыва.
