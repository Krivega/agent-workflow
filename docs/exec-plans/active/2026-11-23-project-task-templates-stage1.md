# Предложение ADR о шаблонах задач и маршрутах ролей

Этап 1 [плана шаблонов и маршрутов](2026-11-22-project-task-templates-and-routes.md).
Результат этапа — ADR со статусом `proposed` в каталоге решений и запись в его реестре.
Реализация CLI, SDK и Temporal и приёмка сквозного маршрута относятся к следующим этапам.

## Критерии приёмки

- [ ] VERSION: ADR описывает выбор и закрепление версии шаблона и маршрута, допустимые уточнения карточки и происхождение итоговых значений.
- [ ] ROUTE: На примере изменения API показаны два независимых шага, обязательные выходы обоих для архитектора и поведение при отсутствии либо ошибке входа.
- [ ] COMPAT: Описаны совместимость прежних дескрипторов и входов SDK, воспроизведение истории Temporal и независимость приёмки по ADR-0049.
- [ ] REVIEW: Указаны рассмотренные варианты, последствия и способ проверки решения. Предложение включено в реестр и проходит проверки документов и ADR.
