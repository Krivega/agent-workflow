# Локальное продолжение Temporal-миграции, 2026-11-17

Поручение текущего чата разрешает локальную Temporal-службу для полного `yarn validate`,
исправление ошибок и параллельное продолжение реализации. Установка, настоящие модельные
запуски, эксплуатационное восстановление и T6 не выполняются. Исходные изменения и Git index
сохраняются; исторические FAIL/UNKNOWN не заменяются.

## Изменения

- TEMP-10: `stageRestore` синхронизирует родительский каталог сразу после создания
  destination. При `EIO` этой синхронизации восстановление не возвращает `staged` и не публикует результат;
  резервная копия остаётся неизменной. Частичный каталог сохраняется для сверки.
- TEMP-17/18: офлайн-журнал версии 2 сверяет квитанции с перечисленными первичными JSONL
  через существующий `readComparisonUsage`. Весь transcript и границы закреплены hashes;
  один сеанс имеет один transcript pin на всю серию, непересекающиеся диапазоны допустимы.
  Сохранены оба формата первичного учёта, неизвестные показатели и версия 1 журнала.

Первичная сверка журнала версии 2
подтверждает только перечисленные диапазоны; он не обнаруживает всех участников и затрат.
Всегда сохраняются `mayRun:false`, `qualification:false`, `allowedModelStarts:0`,
`authorization:null`. Исполнитель 24 выполнений и адаптеры H02/H03/H05 остаются открытыми;
имеющиеся H01/H04/H06 имеют разные договоры и не образуют общего исполнителя.

Независимое ревью исправления T4 не нашло P1/P2. Ревью первичного учёта выявило двойной
учёт одного сеанса через два экспорта разных форматов; исправлено общей привязкой
session → transcript pin с регрессиями в одном/разных блоках. Повторное ревью — без P1/P2.
