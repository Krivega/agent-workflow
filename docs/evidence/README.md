# Доказательства, необходимые миграции

[Результаты прежних срезов миграции](temporal-migration-progress-20261116.md) содержат
сохранённые записи проверок и границы их применения. Это адресный маршрут к прежнему
результату; текущие критерии остаются в действующем плане.

В рабочем репозитории остаются материалы с действующим проверяющим потребителем:

| Материалы | Потребитель |
| --- | --- |
| `tests/fixtures/qualification/` и [источники H06](qualification) | Закреплённые входы регрессий H01–H06 и первичное решение H06/4 |
| H06/3 | Первичные решения по автономному восстановлению [Legacy](h06-autonomous-recovery-v3/primary-approval.json.gz) и [Temporal](h06-autonomous-recovery-v3/primary-temporal-approval.json.gz) |
| `tests/temporal/histories/` и [архив replay](temporal-replay) | Replay предыдущих версий, TEMP-11 |
| [Источники TD-054](td054-deadline-reference) | Отличие первичного поручения от служебного сообщения |
| Адресно используемые ADR в `docs/design/decisions/inherited/` | Действующие предметные гарантии, LOAD, независимость ролей, Temporal и границы перехода |

Записи с путями исходных запусков хранятся в `.gz`. Исходные байты открываются через
`gzip -dc`. Replay ищет истории по имени из исходного манифеста внутри текущей копии
репозитория и проверяет размер и SHA-256 распакованных данных. Регрессии H06 и TD-054
читают сохранённые записи из той же копии.
Для живого запуска нужны собственные входы, пути и допуск из текущего рабочего контура.

Проверку чтения архивов и регрессии H06 и TD-054 запускают из корня репозитория
с установленными зависимостями.

```sh
node --test tests/temporal/historySources.test.mjs
yarn test tests/comparisonH06TemporalAutonomousAuthority.test.ts tests/td054DeadlineReference.test.ts
```

Для replay историй выполните `yarn build`, затем `yarn test:replay`. Команды в исторических
отчётах относятся к указанным в них срезам. Остальные текущие проверки описаны в
[стратегии тестирования](../testing/strategy.md).
