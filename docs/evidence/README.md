# Доказательства, необходимые миграции

[Результаты прежних срезов миграции](temporal-migration-progress-20261116.md) содержат
сохранённые записи проверок и границы их применения. Это адресный маршрут к прежнему
результату; текущие критерии остаются в действующем плане.

В рабочем репозитории остаются материалы с действующим проверяющим потребителем:

| Материалы | Потребитель |
| --- | --- |
| `tests/fixtures/qualification/` и [источники H06](qualification) | Закреплённые входы регрессий H01–H06 и первичное решение H06/4 |
| H06/3 | Первичные решения по автономному восстановлению [Legacy](h06-autonomous-recovery-v3/primary-approval.json) и [Temporal](h06-autonomous-recovery-v3/primary-temporal-approval.json) |
| `tests/temporal/histories/` и [архив replay](temporal-replay) | Replay предыдущих версий, TEMP-11 |
| [Источники TD-054](td054-deadline-reference) | Отличие первичного поручения от служебного сообщения |
| Адресно используемые ADR в `docs/design/decisions/inherited/` | Действующие предметные гарантии, LOAD, независимость ролей, Temporal и границы перехода |

Replay ищет записи по имени из исходного манифеста внутри текущей копии репозитория
и проверяет прежние размер и SHA-256. Пути в записанных событиях относятся к исходным
запускам. Регрессии H06 и TD-054 подставляют записи журнала из сохранённых файлов.

Исторические копии планов, отчёты выделения и квалификации, старые inventories и справки
без проверяющего потребителя удалены из рабочего дерева по поручению пользователя.
Их исходные байты, hashes и снимок индекса до очистки сохранены вне репозитория:

`/Users/krivega/.codex/agent-workflow-evidence/temporal-scope-cleanup-20261116-2fui77_o`

`manifest.json` перечисляет удалённые пути и hashes; `removed/` содержит исходные байты.

Удаление справок не закрывает критерии плана, не возобновляет старые разрешения и не меняет
состояния реальных задач. [План миграции](../exec-plans/active/2026-11-23-temporal-production-rollout.md)
остаётся единственным владельцем реализации и квалификации Temporal.
