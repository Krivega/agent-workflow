# Адаптер H04 и серия из шестнадцати позиций, 2026-11-17

Этап продолжает реализацию H04 для Legacy и Temporal и общей серии. Локальный Temporal
разрешён ранее только для полного `yarn validate`; живые H04-модели, установки и T6
не запускаются. Установочная приёмка остаётся в конце T5 перед T6.

## Реализация

H04 имеет собственные request/grant/spec/entrypoint и общий interval/guard/keeper.
Операция длится не менее 35000 мс и сохраняет шесть промежуточных записей. Legacy
использует существующий ожидающий progress owner, Temporal — Workflow/Activity на службе
внешнего оператора. Прежний model-free helper сохраняет свою отдельную область.

Native waiter работает только на чтение, без TSX, записи кеша или новых прав. Host
начинает операцию после первичного события точной команды waiter. Один launch и один
ожидающий вызов связываются с исходным native-ходом, процессом, первичным результатом
и STOP. Применение выполняется владельцем после этой проверки, ровно один раз.
Неподтверждённое ожидание не разрешает применение или новый запуск.

Версия 4 серии поддерживает первые шестнадцать позиций расписания 24: H01–H04,
по четыре каждого сценария. Версии 1–3, общий cap, pending/lock и блокировка после
FAIL/UNKNOWN сохраняются. Следующий программный адаптер — H05.

Независимое ревью закрыло причинную связь gate с точным native item, границу применения
после ожидания и STOP, поддерживаемый формат header + JSON и привязку host request к
sealed request. После последнего await перед apply повторяются проверки отмены,
времени, неизменных файлов и первичных фактов. Исходный checker FAIL и первичные
квитанции операции/применения сохраняются. Повторное ревью не нашло P1/P2.

## Граница результата

Unit SDK/native transports и синтетическая первичная история проверяют правила допуска,
но не квалифицируют живое ожидание Codex или SDK-жизненный цикл. Физический Node-child
в keeper-профиле также не является модельным запуском. Полная серия 24, живая квалификация,
TEMP-17/18 и T6 остаются открытыми; `partialScope:true`, `qualification:false` сохраняются.
