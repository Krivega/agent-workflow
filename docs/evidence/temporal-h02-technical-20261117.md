# Технический H02, 2026-11-17

Продолжение плана реализует H02 для двух путей с настоящими файлами и существующими
правилами. Установочная приёмка остаётся в конце T5. Native-модели, новые установочные
или эксплуатационные запуски не разрешаются этим техническим результатом; локальный
Temporal используется только в ранее разрешённом полном `yarn validate`.

## Реализация

- `comparisonH02Legacy.ts` использует существующие council, `refreshCouncilInputs`,
  `observeChatCouncil` и порт `AppServerSessions`.
- `comparisonH02Temporal.ts` использует настоящие review/reader Activities,
  scoped LOAD/answer, boundary/control STOP и `finishReview`.
- Две отдельные фиксированные RPC-фабрики работают вне Vitest. Общий CLI `comparison:h02`
  выполняет технический case и сохраняет отчёт. Общий contract берёт материалы и критерии
  непосредственно из `comparison/*.json`; второй алгоритм reuse не создаётся.

Исходная ставка 5 честно даёт FAIL pricing, logging/storage получают PASS своих областей.
После 7 выполняется один новый pricing-обзор; остальные первичные ответы/ссылки сохраняются.
Отдельная проба 7→8 из уже принятого pricing PASS проверяет изменение зависимости;
ставка затем восстанавливается. Остальные пробы проверяют новые зависимости, scope,
основание роли, отсутствующую/неполную карту и исходный открытый FAIL.

Независимое ревью выявило позднюю отмену после последнего модельного обращения в обоих
путях. Исправлены проверки после ожиданий и очистки: отмена даёт unknown, STOP остаётся
доступен, новых запусков нет, исходные доказательства и ставка 7 сохраняются. Повторное
ревью — без подтверждённых P1/P2.
