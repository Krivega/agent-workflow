## Область репозитория для миграции

Пользователь подтвердил область очистки 2026-11-16:

> Да, имею в виду план миграции Agent Workflow на Temporal. Удали всё, что не нужно для его реализации и проверки.

| Состав | Действующий потребитель или критерий |
| --- | --- |
| `src/`, Temporal SDK, Workflow/Activities/Workers | T1–T7, TEMP-01–20 |
| `core/ports/application/adapters/cli`, прежние роли и процедуры | Сравнение T5, переход T6, предметные гарантии и независимая приёмка |
| `comparison/`, `harness2/`, сравниваемые стенды | TEMP-17/18, воспроизведение и учёт затрат |

| `examples/`, `project/`, сборка, статические проверки и CI | TEMP-13–15/20, самостоятельная поставка T7 |
| Действующие инструкции и адресно используемые ADR | Единый владелец правил, LOAD и условия допуска |

Граф импортов с проверками содержит 797 модулей. В исполняемых каталогах без входящих
импортов остаются только три точки входа: `cli/entry.mjs`, `cli/harness2-entry.mjs` и
`src/client/index.ts`. Граф сам по себе не доказывает завершение T6: прежние модули имеют
действующих потребителей и удаляются по условиям соответствующего этапа.

Исторические копии документов, отчёты выделения, отдельные планы текущего чата/передачи,
мобильного доступа и прежние карточки эффективности удалены из рабочего дерева. Первичные
байты удалённых материалов сохранены вне репозитория; место и границы указаны в
[описи](README.md). Изменения кода, тестовых утверждений, покрытия, прав и
реальных состояний задач для этой очистки не требуются.

### Проверка границы очистки

Удалены 96 файлов, 4 816 805 байт; документация сокращена примерно с 5,9 до 1,1 МБ.
`yarn validate:static` прошёл: типы, сборка, архитектура, ESLint, оформление, Markdown и ADR.
`node --test check-areas.profiles.test.mjs tests/temporal/packageClosure.test.mjs` — 20 PASS,
без пропусков. Рабочие file/anchor ссылки проверены; два демонстрационных имени в шаблоне ADR
не являются реальными ссылками. `git diff --check` прошёл.

Хеши исполняемых исходников, тестов, замороженных входов и всех 12 процедур совпали с состоянием
до очистки. Принятые ADR не переписаны. Полный `yarn validate` не запускался: изменение касается
состава документации, а поведение и тестовый договор сохранены. Службы, установки, модели,
рабочий T6 и реальные состояния задач эта проверка не затрагивает.

### Размещение решений и целостность инструкций

По прямому поручению пользователя нужные решения и основания объединены под
`docs/design/decisions`: 18 унаследованных источников в `inherited/`, три первичных основания
в `sources/`. Все 21 файла сохраняют прежние байты. Прежний каталог переноса удалён;
рабочие ссылки используют новые цели. Перенос не меняет принятые решения и состояния задач.

Процедура `relay` версии 5 и её SHA-256 закреплены в текущем `project/workflow.json`;
нормативные фрагменты сохраняют свои IDs и смысл. Профиль coder получает новый SHA-256
изменённой ссылки. Сохранённые дескрипторы, профили, LOAD и квитанции старых задач не обновляются
задним числом; прежняя живая квалификация не переносится на новые байты автоматически.

Проверка принятых ADR допускает изменение только локального адреса основания при неизменных
подписи и полном якоре. Прежние байты читаются из доверенной Git-базы, новые — из рабочей копии;
подмена, отсутствие источника и другие изменения защищённого текста остаются ошибкой.

Проверка переноса: 21 исходный файл совпадает побайтно, каталог переноса отсутствует,
все 12 текущих версий/хешей процедур согласованы. `yarn validate:static` — PASS.
Проверки ADR — 44 PASS; для `scripts/adrChangeValidation.ts` четыре показателя покрытия 100%.
Проверки подключения, coder и обновления — 28 PASS; профили и состав пакета — 20 PASS.
Рабочие file/anchor ссылки и `git diff --check` проверены; первичные снимки сохраняют свои
исторические ссылки. Git index не изменялся.

Полный `yarn validate` для этого изменения не выполнен: обязательные SDK-сценарии запускают
Temporal-сервисы и требуют отдельного применимого допуска по стратегии проверок. Отсутствие
такого допуска блокирует общий допуск, а адресные PASS не выдаются за полный прогон,
новую native-квалификацию или включение T6.

### Общие тестовые данные и сокращённая поставка

19 одинаковых исходных инвентарей историй заменены пятью общими файлами по SHA-256;
14 копий и 720 580 байт исключены. Первичные manifests, имена, origin и хеши не изменялись.
Читатель `historySources.mjs` проверяет размер и хеш до использования общего файла;
повреждённый общий файл не заменяется локальной копией. Все исходные байты доступны.

Состав пакета задаётся положительным списком файлов: полный публичный SDK из `dist` с типами,
CLI и 28 достижимых исходников `src`, необходимые инструкции и нейтральный пример. Карты,
тесты, проверочные потребители, пересмотры сравнительных критериев и Python-стенд исключены.
Публичные exports и bin сохраняются. Закреплённый TypeScript перенесён из devDependencies
в dependencies: его действительно использует runtime-разбор первичных команд CLI.

В обязательный `test:node` добавлены проверки общих данных и настоящей поставки; адресные
профили зарегистрированы отдельно от первоначальной исторической описи проверок.
Проверка архива различает URL каталога и чтение файла: чтение каталога, выход пути и
отсутствующий импорт остаются ошибками. CLI и все публичные SDK-модули загружаются из
распакованного архива с существующими локальными зависимостями, без установки и служб.

`yarn test:node` — 85 PASS, без пропусков; `yarn test:replay` — 265 совместимых историй,
незавершённое ожидание сохранено, несовместимая сборка отклонена, modelStarts 0. Установочная
квалификация с запретом исходников и общий сервисный `yarn validate` этим не заменяются.
