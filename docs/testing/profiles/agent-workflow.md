# Проверки локального процесса агентов

Выбери изменённую границу и открой только её профиль. Команды выполняются из корня
самостоятельного `agent-workflow`; их актуальные имена задаёт `package.json`.

| Что изменилось | Где выбрать сценарий | Уровень и граница |
| --- | --- | --- |
| Типы, правила, CLI или локальный процесс | [Локальные сценарии](agent-workflow/local.md), [Codex и текущий чат](agent-workflow/codex.md) | Адресная регрессия, применимая статика и обязательный полный допуск |
| Workflow, Activity, управление, replay или аудит | [Temporal](agent-workflow/temporal.md) | Модульные проверки и отдельный настоящий SDK; native-вариант квалифицирует собственные первичные операции |
| Поставка, установленный потребитель, backup или восстановление | [Хранение и потребители](agent-workflow/storage-and-consumers.md) | Самопроверка стенда, затем отдельно разрешённые установка и служба; файлы не доказывают восстановление действующих прав |
| Ожидание, H01/H04/H06, сравнительные измерения | [Квалификация и сравнение](agent-workflow/comparison.md) | Подготовка доказательств и сценарии с собственными входами, бюджетом и STOP |
| Только документация | `yarn lint:docs`, `yarn lint:adr`, `yarn lint:docs:references` | Текстовая проверка не даёт нового SDK/native-допуска |

Для кода после профильных проверок обязателен `yarn validate` с четырьмя показателями
покрытия 100% либо явный технический блокер. Полный состав и различие доказательств задаёт
[стратегия](../strategy.md#обязательная-граница), соответствие требований сценариям —
[матрица](../traceability.md). Установки, службы и модели требуют собственного применимого
разрешения. Исторический PASS относится только к своим входам; рабочий T6 из него не следует.

Ниже сохранены адреса прежних разделов для входящих ссылок. Подробности находятся в профилях;
чтение всего каталога для одной задачи не требуется.
