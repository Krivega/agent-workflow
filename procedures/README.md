# Каталог процедур процесса

Режим: **явное подключение отдельных задач через preview/apply с backup и receipt**.
Итоговые доказательства допуска и включения — в [разделе качества](https://github.com/Krivega/agent-workflow/blob/main/docs/quality/README.md).
Проверенные процедуры AW4–AW9 подключены к общему маршруту, но наличие файлов не выдаёт
новых полномочий и не переводит чужую или старую задачу в этот процесс.

Дескриптор [workflow.json](../project/workflow.json) — единственный реестр id/version/hash
и нормативных `fragments`. Блоки `aw-rule` сохраняют текст у прежнего владельца, а сборщик
проверяет точные ID, порядок, полноту каталога и байты без пересказа. Состав нормативных правил
требует независимой проверки; автоматическая сверка её не заменяет. Краткий допуск пока не включён,
его формат и восстановление — в [договоре текущего чата](../CURRENT-CHAT.md#краткий-контекст-после-сжатия).
Файлы ниже — единственные владельцы исполняемых процедур; копии в evidence являются
историческими снимками. [Проектный навык](../.agents/skills/agent-workflow/SKILL.md) направляет текущий чат к этим
владельцам. Копии процедур, скрытые alias и глобальная установка не используются.
Местные адаптации и происхождение — [принятый договор](../docs/quality/agent-workflow-contracts.md).

| Действие | Процедура |
| --- | --- |
| Начало executor/orchestrator/role | [bootstrap](bootstrap.md) |
| Карточка, готовность, владелец и завершение | [task](task.md) |
| Реализация и общий допуск | [implementation](implementation.md) |
| Чтение и запись доказательств | [evidence](evidence.md) |
| Проверка затронутых договоров | [boundary-review](boundary-review.md) |
| Ограниченные A1–A3 | [data-roles](data-roles.md) |
| Planning/acceptance применимых ролей | [council](council.md) |
| Противоречие или три содержательных FAIL | [arbitration](arbitration.md) |
| Независимый аудит по времени | [audit](audit.md) |
| Зависимости дочерних задач и интеграция | [coordination](coordination.md) |
| Нативное сжатие и передача владельца | [relay](relay.md) |
| Отдельные finalization/archive/cleanup | [finalization](finalization.md) |

Перед действием сверь дескриптор, прочитай применимую процедуру и сохрани LOAD с точными
версией/hash и observed read. Неполный дескриптор, отсутствующая процедура, конфликт версии
или неподтверждённый профиль блокируют зависимое действие. Existing native tool и адресное
чтение имеют приоритет; новый помощник требует конкретной необходимости и разрешения.

Подключение, backup/rollback и отключение описаны в [MIGRATION.md](../MIGRATION.md).
Отключённая задача продолжает прежний маршрут AGENTS/PLANS; архивы и проверки не удаляются.
Предметные правила, критерии и полномочия остаются у профильных владельцев репозитория.

Новые запуски текущего чата используют [загрузку по действию](../CURRENT-CHAT.md#загрузка-процедур-по-действию):
каталог остаётся полным, а зависимое действие требует подтверждённое чтение своего набора.
Старые запуски сохраняют полный LOAD; расширение не меняет полномочия и условия завершения.
