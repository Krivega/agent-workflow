# Задача из текущего чата

Выдели цель, границы и критерии, выбери одну карточку. Неоднозначный выбор уточни обычным
вопросом. Технические параметры и журналы готовит агент. Сохраняй профильные навыки анализа,
ADR и ревью; выбор этого навыка не расширяет полномочия.

## Маршрут действий

| Действие | Команда и обязательный договор |
| --- | --- |
| Начало при действующей политике Temporal версии 2 | [`task-chat start` с подготовленным допуском SDK](../../../CURRENT-CHAT.md#запуск-через-temporal) |
| Начало / продолжение / новые требования | [`task-chat start / continue / revise`](../../../CURRENT-CHAT.md#штатный-вход-без-json) |
| Подтверждение чтения | `task-chat load`: [состав по действию](../../../CURRENT-CHAT.md#загрузка-процедур-по-действию), полный наблюдаемый вывод |
| Выбор совета до start/revise | Агент составляет [`--council-selection`](../../../CURRENT-CHAT.md#карта-применимости-совета) по требованиям и потребителям |
| Ожидание запущенного совета | `task-chat wait` с cursor по договору штатного входа |
| Исполнение и проверки | [Runtime-команды](../../../CURRENT-CHAT.md#готовность-исполнение-и-проверки), [ранняя карта требований и reuse](../../../CURRENT-CHAT.md#ранняя-карта-требований-и-адресные-повторы) |
| Пауза, отмена, статус, решения | [Сообщения и полномочия](../../../CURRENT-CHAT.md#сообщения-и-полномочия) и [восстановление](../../../CURRENT-CHAT.md#пауза-отмена-и-восстановление) |

Пользователь передаёт поручение, а не команды или JSON. Пользуйся штатным CLI без одноразового
контроллера. Дальнейшие сообщения относятся к подтверждённой задаче без повторного вызова навыка.
Перед READY обязательны identity/workspace/эффективный профиль и полный observed LOAD текущего
агента. Planning до READY выполняется в чтении; отдельный исполнитель и собственный PASS
не заменяют допуск. Подробности подтверждения хоста принадлежат [его договору](../../../CURRENT-CHAT.md#подтверждение-хоста).

## Владельцы правил

- [Каталог процедур](../../../procedures/README.md) выбирает процедуру
  действия; [дескриптор](../../../project/workflow.json) владеет версиями/hash.
- [Договор совета](../../../CURRENT-CHAT.md#советники-текущего-чата) задаёт
  вызов отдельных read-only сеансов, их origin/binding и повтор у прежнего советника. Покажи роли
  и ссылки пользователю. Внутреннюю процедуру и свой профиль читает сама роль; вызов не требует
  чтения алгоритмов остальных ролей. Полные LOAD и техническая изоляция сохраняются.
- [Миграция](../../../MIGRATION.md) владеет preview/apply, backup/receipt,
  disabled и неизвестными версиями. Автоматически включать отключённую задачу нельзя.
- [Совместимость](../../../CURRENT-CHAT.md#состояние-и-совместимость) и
  штатный вход владеют продолжением, lease, сжатием и незавершёнными операциями.

Уже выданное разрешение сохраняется. Разрешённое узкое исправление дефекта инструмента делай
по AGENTS/PLANS с воспроизведением и регрессионной проверкой, затем продолжай исходную задачу,
сохраняя Store, owner, историю и советников. Само исправление не требует нового продуктового
запуска или повторного planning; новые продуктовые требования проходят revise.

Перед итогом сверь Result, обязательные критерии, фактические проверки и проекцию карточки.
Открытое условие или конфликт запрещают успешное завершение. Финализация, публикация и очистка
имеют отдельные права по применимой процедуре.
