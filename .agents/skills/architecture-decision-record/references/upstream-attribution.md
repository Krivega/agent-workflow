# Upstream attribution

This repository-local skill is an adapted, shortened workflow derived from the general
`architecture-decision-record-skill` in
[`architecture-decision-record/architecture-decision-record`](https://github.com/architecture-decision-record/architecture-decision-record/tree/b1de91256a57110b655ff3572ce1fc41fbc2dac6/skills/architecture-decision-record-skill),
revision `b1de91256a57110b655ff3572ce1fc41fbc2dac6`.

The upstream author's work is offered under
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). This adaptation changes the
workflow for Codex discovery, Russian project documentation, explicit human acceptance,
immutable accepted records, typed relationships, and the local validation command.

The local ADR template also draws on the upstream Important Technical Decisions template at the
same revision. That template is contributed by Ignacio Larrañaga under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The local template combines that
lean option-and-rationale shape with project-specific lifecycle, consequences, verification,
relationships, and review conditions.
