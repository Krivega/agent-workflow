# Навыки разработки инструмента

| Задача | Навык |
| --- | --- |
| Влияние изменения до правки | [analyze-change-impact](skills/analyze-change-impact/SKILL.md) |
| Новое или пересматриваемое архитектурное решение | [architecture-decision-record](skills/architecture-decision-record/SKILL.md) |
| Локальное ревью без изменения файлов | [review-git-branch](skills/review-git-branch/SKILL.md) |
| Явно подключённая задача из текущего чата | [agent-workflow](skills/agent-workflow/SKILL.md) |

Выбор навыка не выдаёт новых полномочий. Разработка самого инструмента не подключает процесс
автоматически. Правила проекта задаёт [AGENTS.md](https://github.com/Krivega/agent-workflow/blob/main/AGENTS.md).
